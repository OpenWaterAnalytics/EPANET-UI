# Fire Flow Analysis
Selecting <b>Project > Report > Fire Flow Report</b> from the Menu Bar will have EPANET-UI perform a fire flow analysis for a designated group of nodes. For each such node, the analysis will determine:
1. The pressure that results when a stipulated target fire flow is added to the node's normal demand.
2. The largest fire flow demand at the node that will maintain pressures above a stipulated target.
This kind of information is used to insure that a distribution system is capable of providing enough water to meet fire fighting requirements.

NOTE:
The EPANET-UI workspace will remain disabled while a File Flow Report is being setup, generated, and viewed.

## Setup

When a Fire Flow Report is requested, a ***Fire Flow Selector*** panel will appear above the Map Viewer panel. It is used to collect the following information:

<u>Target Fire Flow</u><br>
The desired fire flow to be delivered. It must be expressed in the commonly used flow units for fire flow analysis; gpm for US units or lpm for metric units.

<u>Target Pressure</u><br>
The minimum pressure to be maintained under fire flow demands. It must be expressed in the commonly used pressure units for fire flow analysis; psi for US units or kPa for metric units.

<u>Time of Day</u><br>
For extended period analyses, the time of day to analyze.

<u>Node Selection</u><br>
Clicking the Fire Flow Selector's <kbd>Select Nodes</kbd> button will display the Network Map along with a ***Group Selector*** panel used to select a set fire flow nodes. Individual nodes are selected or deselected by clicking them on the Network Map. Nodes can also be selected by the value of their Tag property or by using the mouse to draw a polygon region on the map that surrounds them. Any Reservoir or Tank nodes selected will be excluded from being analyzed. 

<u>Pressure Zone Set</u><br>
This is the set of nodes that must meet the target pressure for each fire flow node analyzed. The choices are:
- only the individual fire flow node itself
- all fire flow nodes
- all network nodes (excluding Tanks and Reservoirs).

Once setup is complete, the fire flow report can be generated by clicking the Selector's <kbd>Compute Fire Flows</kbd> button.

## Analysis

The following steps are performed to find the available fire flow for each node selected for analysis:

- A simulation is run with no fire flow added to the node to establish its static pressure. If that pressure is below the target pressure then the node is assigned an available fire flow of 0.

- Otherwise a second simulation is made with the full fire flow target added to the node's normal demand at the designated time of day. If the target presure is met or exceeded at all nodes in the pressure zone set then the available fire flow is the full target fire flow.

- Otherwise a sequential search procedure is used to find the largest fire flow at the node that will just meet the target pressure in its pressure zone set.

## Results

The results of a Fire Flow Analysis are displayed in the Report Frame which contains three tabbed pages:
- The <b>Summary</b> page summarizes the analysis setup choices and the overall results.
- The <b>Details</b> page contains a table listing results for each node selected for analysis.
- The <b>Map</b> page displays the available fire flow (as a percentage of the target flow) in color-coded fashion on a map of the pipe network.

The figure below gives an example of the table appearing on the Details page of the report. The columns contain the following information:

|                   |                                                       |
|-------------------|-------------------------------------------------------|
| Node              | the ID name of a node selected for fire flow analysis |
| Static Pressure   | the pressure at the node under no fire flow |
| Target Fire Flow  | the desired fire flow demand at the node |
| Residual Pressure | the node's pressure when subjected to the target fire flow |
| Available Fire Flow | the highest fire flow, at or below the target flow, that can be delivered without pressures falling below the target pressure within the node's pressure zone set |
| Critical Pressure | the lowest pressure within the pressure zone set under the node's available fire flow |
| Critical Node     | the ID name of the node in the pressure zone set with the critical pressure |

The table shown above was generated for a target fire flow of 2000 gpm, a target pressure of 20 psi, and a pressure zone set of all selected fire flow nodes. We note the following:
- Node 211 had a pressure of 22 psi under the full target fire flow. It is therefore able to meet the full target flow of 2000 gpm.

- Under the target fire flow, Node 213's pressure was 19 psi. To meet the target pressure its available fire flow had to be reduced to 1950 gpm with Node 213 being the critical node at which the 20 psi target was met.

- Node 253 had a negative pressure under the target fire flow. It's available fire flow had to be reduced by over half to meet the 20 psi target.

- While Node 255 could meet the pressure target under the full target fire flow, the pressure target could not be met at Node 253. To have the latter node meet the target, the available fire flow at Node 255 had to be reduced down to 1830 gpm.
